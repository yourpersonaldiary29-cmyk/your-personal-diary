NOTE 2026-11-08 (TERMS package, docs/apple-tasks/TERMS.md): the checkbox now covers BOTH documents in ONE sentence - "I have read the Privacy Policy and the Terms of Use, and I agree to them" (catalogue key auth.legalConsent with the links {policy} and {terms}; the error auth.legalConsentRequired names both; the former keys auth.privacyConsent / auth.privacyConsentRequired are gone). The registration page sends privacyAccepted: true AND termsAccepted: true. The hosted server requires both flags (policy first): a registration without termsAccepted: true is refused with 400 VALIDATION, field termsAccepted, message server.auth.termsRequired ("... update the app"), and an account created with both records privacyAcceptedAt/privacyVersion and termsAcceptedAt/termsVersion (TERMS_VERSION = legal/settings.json termsEffectiveDate, shared/legal.ts). Local developer mode still requires and records neither. Consequence: an app built BEFORE this change cannot create an account on the hosted server any more (it sends only the policy flag and shows the server message in an alert); signing in is unaffected. No public users exist yet, and the final Windows, Android and Mac builds of the sprint carry the new form.
