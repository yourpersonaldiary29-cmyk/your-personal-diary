PACKAGE SHOTS - App Store screenshots (iPhone and Mac) in 19 App Store localizations, and the 1024 px app icon.

HOW SCREENSHOTS ARE MADE HERE (read the file header of scripts/play/render-screenshots.mjs in full before anything else): a local hosted server from source with fictional accounts and the localized demo data, headless Microsoft Edge through playwright-core from the tool folder (TOOL_DIR = <project>/mpd-store-tools, which exists with node_modules/playwright-core; Edge at C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe), a profile = viewport + device scale + shot list + output folders, a layout probe that refuses cut or covered text. The "phone" profile produced play/screenshots (1080x1920, 7 shots) and the "desktop" profile produced store/screenshots (1920x1080, 8 shots). Those two profiles and their outputs MUST stay byte-identical in behaviour (do not re-render them; do not change their code paths; a refactor that moves shared code is fine only if the phone/desktop configuration values stay exactly the same - prove it by diffing the PROFILES entries before/after).

INPUTS: docs/apple-tasks/APPSTORE-FACTS.md section 6 and 7 (sizes, formats, limits - read it first; if it says a different accepted size than below, follow it and say so), appstore/locales.json (the folder codes; if LISTING has not written it yet, use the mapping in docs/apple-tasks/ENV-FINAL.md and name the file in openIssues), design/app-icon.svg and src-tauri/icons/icon.png (icon sources), store/screenshots/captions.json and README.md (what each desktop shot shows), play/screenshots/README.he.md.
