# ערכת Google Play – דף החנות (טקסטים וגרפיקה)

מה יש בתיקייה הזו ומה מעלים לאן ב-Play Console. (הוראות השחרור המלאות – יצירת האפליקציה, החתימה, מסלול הבדיקה הסגורה – נמצאות ב-`docs/PLAY-RELEASE.he.md`.)

## מה יש כאן

| קובץ | מה זה | לאן מעלים |
|---|---|---|
| `listing/<קוד שפה>/title.txt` | שם האפליקציה – תמיד **Your Personal Diary**, באנגלית, בכל השפות (עד 30 תווים) | שדה **App name** |
| `listing/<קוד שפה>/short.txt` | תיאור קצר, שורה אחת (עד 80 תווים) | שדה **Short description** |
| `listing/<קוד שפה>/full.txt` | תיאור מלא (עד 4000 תווים) | שדה **Full description** |
| `graphics/icon-512.png` | אייקון 512×512, PNG של 32 ביט עם ערוץ שקיפות (ריבוע מלא – Play מעגל את הפינות בעצמו) | **App icon** |
| `graphics/feature-1024x500.png` | תמונת הכותרת 1024×500, PNG של 24 ביט בלי שקיפות, בלי טקסט – קובץ אחד לכל השפות | **Feature graphic** |
| `last-upload.json` | רישום ה-versionCode האחרון שהועלה – שייך להוראות השחרור, לא לדף החנות | לא מעלים |

20 תיקיות השפה נקראות בדיוק לפי הקודים של Play: `en-US` (ברירת המחדל), `iw-IL` (עברית – כך היא מופיעה ב-Play, לא `he-IL`), `ar`, `zh-CN`, `ja-JP`, `hi-IN`, `th`, `es-ES`, `pt-BR`, `fr-FR`, `it-IT`, `de-DE`, `ro`, `el-GR`, `pl-PL`, `cs-CZ`, `hu-HU`, `ru-RU`, `bg`, `tr-TR`.

צילומי המסך – סט של 7 צילומים לכל אחת מ-20 השפות, באותם שמות תיקיות – נמצאים ב-`play/screenshots/`. מה מעלים לאן, ואיך מייצרים אותם מחדש: `play/screenshots/README.he.md`.

## מה מעלים לאן

1. **Grow users ← Store presence ← Main store listing** (דף החנות הראשי, באנגלית):
   - מעתיקים את שלושת הקבצים של `listing/en-US/` לשדות App name, Short description ו-Full description. פותחים את הקובץ בעורך טקסט (למשל Notepad), מסמנים הכול ומדביקים – בלי לשנות דבר.
   - בקטע **Graphics**: מעלים את `graphics/icon-512.png` ל-App icon ואת `graphics/feature-1024x500.png` ל-Feature graphic. שניהם חובה.
2. **תרגומים** – באותו דף: **Manage translations ← Select languages**, מסמנים את 19 השפות האחרות (לפי שמות התיקיות שלמעלה) ← **Apply and Save**. אחר כך בוחרים כל שפה ומדביקים את שלושת הקבצים מהתיקייה שלה.
   - את הגרפיקה **לא** צריך להעלות שוב לכל שפה: שפה בלי גרפיקה משלה מציגה את זו של האנגלית.
3. **לא** מדביקים קישורים בתיאורים. כתובת מדיניות הפרטיות נכנסת לשדה משלה (App content ← Privacy policy) – ראו `docs/PLAY-RELEASE.he.md`.

## לפני ההעלאה – בדיקה

```
node scripts/play/check-listing.mjs
```

בודק את כל 60 הקבצים: אורכים לפי Play, שלושת הקבצים בכל שפה, בלי קישורים, אמוג'י, אותיות גדולות לצעקה, "הכי טוב / #1 / חינם", חזרה מוגזמת על מילים, טקסט שלא תורגם – ובלי טענות שכבר לא נכונות ("נשמר רק במכשיר", "בלי ענן", "הצפנה מקצה לקצה"). התוצאה הרצויה: `check-listing: 20 locales, 60 files, all within Play's limits and rules`.

אם האייקון של האפליקציה משתנה (`src-tauri/icons/icon.png`), מייצרים את הגרפיקה מחדש:

```
node scripts/play/render-graphics.mjs
```

## כדאי לדעת

- הטקסטים מתארים את האפליקציה כפי שהיא: היומן נשמר מוצפן בחשבון שלך בשרת, מסתנכרן בין מכשירים, וממשיך לעבוד כשאין חיבור. אם משהו מזה משתנה – מעדכנים את הטקסטים לפני השחרור הבא.
- הפורטוגזית של האפליקציה עצמה היא של פורטוגל, ואילו התיאור ב-Play נכתב לברזיל (`pt-BR`), כי משתמשי ברזיל הם הרוב. אם תרצו – אפשר להוסיף ב-Play גם `pt-PT` ולהדביק בו את אותם קבצים.
