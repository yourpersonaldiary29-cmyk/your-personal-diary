_bg - the Bulgarian App Store texts, kept for reuse (not an App Store Connect folder)

App Store Connect has no Bulgarian localization, so nothing from this folder can be pasted into App Store Connect today: appstore/listing/bg/NOTE.txt and appstore/locales.json ("bg": folder null) record that decision, and a Bulgarian reader sees the English (U.S.) page. The texts were nevertheless translated from appstore/listing/en-US/ on 2026-11-08 (LISTING package, translator B, docs/apple-tasks/LISTING.md), in the same ten files as every other folder (name.txt and name-mac.txt stay in Latin letters), so that they can be reused elsewhere - a web page, another store, or App Store Connect itself if Apple adds Bulgarian one day. In that case: delete appstore/listing/bg/ (the note folder), rename this folder to Apple's code, put that code in appstore/locales.json under "bg" (folder and appleName), delete this NOTE.txt, and run node scripts/appstore/check-listing.mjs.

The leading underscore makes the command node scripts/appstore/check-listing.mjs skip the folder (appstore/README.md, section 1: folders starting with "_" are drafts or archives). The scripts test checks it with every rule of the other folders instead: scripts/appstore/check-listing.test.mjs, test "the Bulgarian draft _bg (kept for reuse, skipped by the command) follows the same rules", copies it under a temporary code next to en-US and runs the checker, including the minimum age of legal/settings.json (run node --test scripts/appstore/check-listing.test.mjs). Result on 2026-11-10: every limit and rule met - subtitle 30 of 30 characters, promotional text 162 of 170, description 3929 of 4000, keywords 86 of 100 UTF-8 bytes, what's new 301 of 4000.

Register: formal "вие", the same as the app's own Bulgarian texts (shared/i18n/messages/bg/) and the Microsoft Store listing (store/listing/bg-BG/).

‎_bg - הטקסטים בבולגרית לחנות של אפל, שמורים לשימוש חוזר (זו לא תיקייה של App Store Connect)

ב-App Store Connect אין בולגרית, ולכן אי אפשר להדביק שם כלום מהתיקייה הזאת היום - ראו appstore/listing/bg/NOTE.txt. בכל זאת תרגמנו את כל הטקסטים מאנגלית (2026-11-08), באותם עשרה קבצים כמו בכל תיקייה אחרת, כדי שאפשר יהיה להשתמש בהם במקום אחר: בדף אינטרנט, בחנות אחרת, או ב-App Store Connect אם אפל תוסיף בולגרית בעתיד. במקרה כזה: מוחקים את התיקייה appstore/listing/bg (תיקיית ההסבר), משנים את שם התיקייה הזאת לקוד של אפל, רושמים את הקוד ב-appstore/locales.json תחת "bg", מוחקים את הקובץ הזה ומריצים node scripts/appstore/check-listing.mjs.

הקו התחתון בתחילת שם התיקייה גורם לפקודת הבדיקה לדלג עליה. במקומה בודקת אותה בדיקת הסקריפטים (node --test scripts/appstore/check-listing.test.mjs) - באותם כללים כמו כל תיקייה אחרת, כולל הגיל המינימלי מ-legal/settings.json. התוצאה ב-2026-11-10: הכול בתוך המגבלות (מילות החיפוש: 86 מתוך 100 בייט).
