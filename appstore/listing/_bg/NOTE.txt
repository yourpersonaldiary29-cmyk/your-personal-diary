_bg - the Bulgarian App Store texts, kept for reuse (not an App Store Connect folder)

App Store Connect has no Bulgarian localization, so nothing from this folder can be pasted into App Store Connect today: appstore/listing/bg/NOTE.txt and appstore/locales.json ("bg": folder null) record that decision, and a Bulgarian reader sees the English (U.S.) page. The texts were nevertheless translated from appstore/listing/en-US/ on 2026-11-08 (LISTING package, translator B, docs/apple-tasks/LISTING.md), in the same nine files as every other folder, so that they can be reused elsewhere - a web page, another store, or App Store Connect itself if Apple adds Bulgarian one day. In that case: rename this folder to Apple's code, put that code in appstore/locales.json under "bg", delete this NOTE.txt, and run node scripts/appstore/check-listing.mjs.

The leading underscore makes scripts/appstore/check-listing.mjs skip the folder (appstore/README.md, section 1: folders starting with "_" are drafts or archives). The texts were still checked once with the same rules, by copying the folder under a temporary name next to a copy of en-US and a temporary locales.json that maps bg to it; the result (every limit and rule met, keywords 86 UTF-8 bytes) is in the translator's report of 2026-11-08.

Register: formal "вие", the same as the app's own Bulgarian texts (shared/i18n/messages/bg/) and the Microsoft Store listing (store/listing/bg-BG/).

‎_bg - הטקסטים בבולגרית לחנות של אפל, שמורים לשימוש חוזר (זו לא תיקייה של App Store Connect)

ב-App Store Connect אין בולגרית, ולכן אי אפשר להדביק שם כלום מהתיקייה הזאת היום - ראו appstore/listing/bg/NOTE.txt. בכל זאת תרגמנו את כל הטקסטים מאנגלית (2026-11-08), באותם תשעה קבצים כמו בכל תיקייה אחרת, כדי שאפשר יהיה להשתמש בהם במקום אחר: בדף אינטרנט, בחנות אחרת, או ב-App Store Connect אם אפל תוסיף בולגרית בעתיד. במקרה כזה: משנים את שם התיקייה לקוד של אפל, רושמים את הקוד ב-appstore/locales.json תחת "bg", מוחקים את הקובץ הזה ומריצים node scripts/appstore/check-listing.mjs.

הקו התחתון בתחילת שם התיקייה גורם לסקריפט הבדיקה לדלג עליה; הטקסטים נבדקו פעם אחת באותם כללים דרך עותק זמני, והתוצאה (הכול בתוך המגבלות) רשומה בדוח של המתרגם.
